## 背景介绍

clash verge 支持tun模式, 可以接管所有流量, 比较好用, 但是开启tun模式后也会有一些小问题. 

日常工作中，经常需要telnet一些地址来测试这个地址通不通,如果clash开启了tun模式以后呢，你的telnet就会显示所有的地址都是通的, 就会让你的那个判断有些迷惑.

## 根本原因

开启 TUN Mode 后，telnet 已经不再适合作为判断目标端口是否可达的工具。
原因如下：

```
telnet
    │
    ▼
macOS TCP
    │
    ▼
utun (Clash TUN)
    │
    ▼
Mihomo
    │
    ├── telnet 已经收到 "连接成功"
    │
    ▼
Mihomo 再去真正连接目标服务器
```

因此：

* telnet xx.xx.xx.xx 80
* telnet 一个不存在的IP 80

都会先看到

```
Connected to ...

```
真正连接失败时，Mihomo 才会关闭连接。

## 解决方式

telnet的时候`关闭tun模式`就可以了
