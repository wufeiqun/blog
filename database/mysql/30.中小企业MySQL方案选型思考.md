## 核心原则



#### 一、员工禁止本地直连生产数据库

技术手段：`网络策略`



#### 二、账号分离

|          账号类型           | 账号                              | 备注                                                         |
| :-------------------------: | --------------------------------- | ------------------------------------------------------------ |
|          超管账号           | root                              | 数据库最高权限，只有运维人员会用到                           |
|       数据库平台账号        | ops/slowlog/rep等根据公司具体场景 | 比如数据库管理平台，BI报表同步，慢SQL查询平台等，需要的权限比普通的业务的账号权限大。 |
|     业务系统使用的账号      | app_rw, app_r                     | 业务系统使用的账号，需要有读写的账号和只读的账号             |
| 开发人员排查问题/查询数据等 | 数据库平台/堡垒机授权             | 包括只读账号和读写账号， 特点是有时效性。推荐大部分场景都通过数据库平台 |
|                             |                                   |                                                              |
