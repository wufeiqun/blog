遇到了好几次, 都是这个数据库, 这里总结一下.

## 根因分析

根据跟AI的对话, 结论是开发创建表字段太多, 总长度超过了innodb的限制.

至于为什么主库上可以创建成功, 那是因为开发同事在创建表的时候, 临时加上了如下的配置:

```
SET GLOBAL innodb_strict_mode=OFF;
```

## 解决方式

#### 短期解决

主库和从库都加上如下的配置, 这样即使创建的表不符合规范, MySQL也只是提醒一下, 不会报错.

```
SET GLOBAL innodb_strict_mode=OFF;
```

#### 长期解决

让开发同事创建符合规范的表.
